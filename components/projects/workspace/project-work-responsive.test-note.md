# Project Tasks responsive validation matrix

- Mobile (<768px): stacked status buckets; Task Details in BottomSheet.
- Tablet (768–1279px): board remains single-column workspace; support panels reflow below; Task Details available inline.
- Laptop/Desktop (1280–1799px): Active Phases + dominant Execution Board; support panels below; Kanban scroll region preserves four readable columns.
- Wide desktop (>=1800px): Active Phases + Execution Board + support rail; board retains a 640px minimum track and internal horizontal scrolling when required.
