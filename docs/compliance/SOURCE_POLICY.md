# Compliance Source Policy

B.O.S. legal/compliance rule packs must be based on authoritative primary law or official agency material where available. Each rule pack should preserve jurisdiction, rule identifier, version, effective-date context, and source references. Secondary commentary may help explain implementation but must not silently become the controlling rule source.

When source authority, effective date, applicability, or required facts are uncertain, the engine must fail to `REVIEW_REQUIRED` rather than infer a compliant result.
