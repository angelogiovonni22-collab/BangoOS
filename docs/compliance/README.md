# B.O.S. Compliance Engineering

This directory documents the compliance-support architecture and its release phases.

- `ohio-residential-contract-compliance.md` — current Ohio residential contract controls.
- `COMPLIANCE_ROADMAP.md` — phased expansion plan and completion criteria.

Compliance logic is designed to fail safely: ambiguous legal classifications require review; deterministic server-side gates cannot be bypassed by UI or Orion; historical evaluations and material lifecycle events are preserved for audit.
