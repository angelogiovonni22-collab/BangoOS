# B.O.S. Future 2030 Experience

Future 2030 is the first B.O.S. appearance option that intentionally changes layout treatment as well as color tokens.

## Experience principles

- preserve the same B.O.S. routes, records, permissions, business logic, and Orion provider architecture
- keep all primary text and controls readable against dark translucent surfaces
- use floating navigation and detached top-bar geometry on desktop
- use glass intelligence surfaces, HUD-like accent rails, subtle grid depth, and restrained motion
- retain the normal mobile drawer pattern instead of forcing the desktop spatial layout onto small screens
- respect `prefers-reduced-motion`
- remain selectable and persistent through Settings → Appearance using the existing theme storage contract

## Current Future 2030 transformation

- floating rounded navigation capsule on desktop
- detached glass command top bar
- spatial grid workspace background
- cyan/violet ambient intelligence fields
- HUD-style page header treatment
- glass cards with active edge illumination
- KPI scan-line detail and depth response
- technical table hover state
- focused form-control illumination

This experience is presentation-only. It must never fork B.O.S. data models or create alternate business workflows.
