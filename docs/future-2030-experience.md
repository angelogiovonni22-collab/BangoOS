# B.O.S. Neon Grid Command Experience

Neon Grid Command replaces the original Future 2030 visual treatment while retaining the stable `future-2030` theme identifier for saved-device compatibility. It is an original B.O.S. interface experience inspired by luminous digital command decks, not by any external brand assets or logos.

## Experience principles

- preserve the same B.O.S. routes, records, permissions, business logic, and Orion provider architecture
- retain high readability on near-black surfaces
- use sharp technical geometry rather than rounded generic glass cards
- use electric cyan as the primary circuit/light language with restrained blue depth
- create a luminous perspective floor grid and subtle technical ceiling grid without interfering with content
- retain the normal mobile drawer architecture and touch usability
- respect `prefers-reduced-motion`
- persist through Settings → Appearance using the existing B.O.S. theme storage contract

## Neon Grid transformation

- near-black command deck with electric cyan circuitry
- luminous perspective floor grid plus faint technical background grid
- sharp clipped navigation rail and HUD panels
- cyan scan line on the command bar
- active navigation edge lighting
- page headers with illuminated HUD rails and corner cuts
- dark circuit-module cards with neon edge response
- KPI cards with live cyan status rails
- technical table rows with edge illumination
- hard-edged focused form controls
- Orion panel visual integration without changing Orion runtime behavior

This experience is presentation-only. It must never fork B.O.S. data models, permissions, routes, or operational workflows.
